# Session hand-offs

One file per working session, `YYYY-MM-DD-<topic>.md`, written by `/session-handoff`
(`.github/prompts/session-handoff.prompt.md`) and audited at the start of the next session by
`/verify-handoff`. Hand-offs are history; durable knowledge is promoted to `../DECISIONS.md`,
`../MEMORY.md` and `../../CHANGELOG.md`.
