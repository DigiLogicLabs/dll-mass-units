# Plugin Usage Guide

The maintained [quick start](docs/quick-start.md) and [usage guide](docs/usage.md) cover the placeable spawner, unit templates/handles, movement, navigation, formations, default and custom rendering, selective GAS/Behavior Tree bridges, and C++ access for version 1.2.0.

For installation and packaging, see [docs/setup.md](docs/setup.md). GASCompanion is not a dependency.
