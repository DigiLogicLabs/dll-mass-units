# Security policy

**Please do not report security problems in public issues.** Use GitHub's private reporting instead: the
**Security** tab of [dll-mass-units](https://github.com/DigiLogicLabs/dll-mass-units) → **Report a vulnerability**. We reply as soon as we can, agree a fix and a
disclosure date with you, and credit you in the CHANGELOG unless you prefer otherwise.

**Supported versions:** the latest `main`. Fixes are not back-ported to older versions.

**Scope:** this plugin's own code. Problems in Unreal Engine itself go to Epic Games; problems in an online
service (Steam, EOS) go to that service.
